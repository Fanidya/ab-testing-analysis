# A/B Testing Analysis for E-Commerce

## Summary
An A/B testing analysis comparing control and treatment conversion rates
with statistical hypothesis testing and daily conversion trends.

## Project Structure
- notebooks/ab_testing_analysis.ipynb — Main analysis notebook
- data/ — Raw and processed datasets
- images/ — Visualizations and charts

## How to Run
1. Download ab_data.csv from the link in data/README.md
2. Place it in the data/ folder
3. Open notebooks/ab_testing_analysis.ipynb in Google Colab
4. Run all cells

## Tools Used
- Python, pandas, NumPy, SciPy, statsmodels
- DuckDB SQL
- Tableau Public
- Matplotlib, Seaborn
